# Resume-Ready Project Summary

Built an end-to-end credit risk analytics project using Lending Club loan data, SQL, Python, pandas, scikit-learn, and Power BI-ready exports. Defined a binary historical default target, performed portfolio risk analysis, trained a Logistic Regression PD model, evaluated discrimination and calibration with ROC-AUC, KS, Brier score, and confusion-matrix metrics, and segmented borrowers into configurable analytical risk bands.
